冷静、可信的财务工作台

近中性冷灰底、一种强调蓝、绿红只留给收入与支出。墨色主按钮，1px 边框代替阴影与渐变，Geist + Noto Sans SC 的等宽数字让每一笔金额对齐。下方所有组件在浅色与深色下并排呈现——这套 token 确认后将原样落入 index.css。

方向
克制的金融工作台（Linear / Vercel / Mercury 一路）
字体
Geist（UI 与数字）· Noto Sans SC（中文）· Geist Mono（ID）
主题
浅 / 深 / 跟随系统；WORK / LIFE 只切换模式色
范围
应用外壳与 17 个页面、登录与邮件确认页、PWA 资源、邮件模板

取舍

相对现有界面与被回滚的 #117，哪些去掉、哪些保留、哪些新增。

去掉

  • 紫色渐变 hero、模糊光斑、紫色光晕阴影
  • 全站衬线字体与「纸张 / 账本」质感
  • 大圆角与厚阴影堆叠
  • 页面里逐处手写 dark: 与调色板类名
  • 移动端磁吸悬浮模式按钮

保留

  • 三根上升柱的品牌标识（重新配色）
  • WORK / LIFE 双模式与全部功能、文案、i18n key
  • 侧栏 + 移动底栏的导航结构与「更多」抽屉
  • 现有动效时长与曲线（180–300ms，easeInOut）
  • 所有 e2e 与源码策略测试依赖的角色与字面量

新增

  • 一套语义 token（浅 / 深各一份），组件不再关心主题
  • ui/ 原语：Button、Field、Card、Badge、Segmented、Dialog…
  • 三态主题切换（浅 / 深 / 系统）与 reduced-motion 支持
  • 可访问的对话框取代裸浮层与 window.prompt
  • 图表配色改用经色觉缺陷校验的 8 色序列，超出折叠为「其他」
